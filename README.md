# Stove-Dark-Mode
Enable dark mode on https://page.onstove.com/ because I HATE GETTING FLASHED when reading patch notes!!

## Installation 

**Step 1:** Install the [Tampermonkey](https://www.tampermonkey.net/) extension.

**Step 2:** **[Click here to install the script](https://raw.githubusercontent.com/DEX-1101/Stove-Dark-Mode/main/stove_dark_mode.user.js)**, then click the **"Install"** button when the Tampermonkey tab automatically opens.
